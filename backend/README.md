# Backend Challenge

Build a process that logs into a demo banking application, extracts all transactions across the full available history, and stores them in a database.

## Objective

Create a solution that can:

1. Log in to the demo bank application.
2. Complete the OTP step.
3. Retrieve all transactions from all available time.
4. Persist those transactions into a database (any database).

The solution must be implemented in Python.

## Demo Application

- URL: [https://demo-bank-2.vercel.app/](https://demo-bank-2.vercel.app/)
- Username: `user`
- Password: `pass`
- OTP: `123456`

## Expected Outcome

By the end of the exercise, we should be able to run your solution using the instructions you provide and have all available transactions from the demo bank stored in a database.

## Submission

Please hand over your solution as a GitHub repository.

Your repository should include clear instructions for how to run the project locally, including any setup steps, dependencies, configuration, and commands required to execute the process end to end. `just` is your friend.
