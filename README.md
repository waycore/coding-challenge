# Coding Challenges

This repository contains the coding challenges used by Waycore across different disciplines.

Each challenge lives in its own folder and includes a dedicated `README.md` with the full brief, requirements, and submission instructions.

## Challenges

- [Backend Challenge](./backend/README.md): Build a process that logs into a demo bank, extracts all historical transactions, and stores them in a database.

## Candidate Expectations

Candidates are allowed, and are in fact expected, to use AI coding tools while completing these exercises.

That said, the final submission should still reflect clean, professional engineering work. The code should be well-structured, readable, and maintainable, and the candidate should be able to clearly explain how their solution works, why they made the choices they did, and what trade-offs those choices involve. 

We also expect to see solid tests. Everything is a prompt away.
